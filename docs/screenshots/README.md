# Screenshots

PNG files are not committed here — binary files bloat a git repository and
every clone would have to download them forever.

To see Nova for yourself, it takes about two minutes:

```cmd
SETUP.bat
START.bat
```

No API key yet? Set `AI_OFFLINE_MOCK=1` in `.env` and the whole interface
works with fake replies.

If you want to add screenshots to your own fork, drop the PNG files in this
folder and reference them from the main `README.md`, for example:

```markdown
![Chat](docs/screenshots/01-chat-dark.png)
```
